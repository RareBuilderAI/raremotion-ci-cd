# Raremotion Automated Testing & CI/CD

A Python project demonstrating automated software testing
and Continuous Integration using GitHub Actions.

## Technologies
- Python
- Pytest
- GitHub Actions
- Git and GitHub

## Features
- Automated unit testing
- Five test cases
- Division-by-zero error handling
- Automatic testing on GitHub pushes and pull requests
- CI pipeline running on Ubuntu

## Run Locally

Create a virtual environment:

python3 -m venv .venv

Activate it:

source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt

Run tests:

python -m pytest -v

## CI Pipeline

GitHub Actions automatically installs dependencies
and runs automated tests whenever code is pushed
or a pull request is opened.
